## Problem

People have no easy way to remember what they paid for items or where they got the best price. When a store has a sale, there's no way to tell if it's actually a good deal compared to what you've paid before. Over time, it's hard to see how much you're really spending each day, each month, etc.

## Initial requirements

- R1: The user can log a purchase with item name, price, store, and date
- R2: The user can look up the price history of any item
- R3: The user can see which store had the cheapest price for an item
- R4: The user can view total spending over a time period (daily, monthly)
- R5: All data is saved to a local file
- R6: The app runs from the command line with arguments
